# Limitations & next steps

Full discussion: `../paper/paper.md` §6, and `../website/limitations.html`.

1. **Cross-sectional design** — no causal inference possible. → longitudinal study.
2. **Self-report only** — social desirability, recall bias. → triangulate with records / teacher ratings / physiological markers.
3. **Non-representative sample** — Indian convenience sample. → replicate across national contexts.
4. **Low reliability** — self-efficacy α = .265, social support α = .572, burnout α = .655 (two-item / multidimensional). → validated multi-item scales (MSPSS, full self-efficacy subscale, complete MBI-SS / SBI).
5. **Performance-inflating choices** — median-split target, N = 321. → continuous outcome, population-referenced threshold, external validation.
6. **Collinearity** — academic stress × distress r = .683. → VIF / ridge / SEM.
7. **One-dimensional burnout** — subscales collapsed. → analyse exhaustion / cynicism / efficacy separately.
8. **Excluded variables** — sleep, screen time (categorical). → ordinal encoding; add sleep quality, GPA, peer relationships.

**Bottom line:** preliminary, proof-of-concept. Shows a strong, consistent,
explainable burnout signal in a small psychometric feature set. Does **not**
establish causation, generalisability, or a deployable screening tool.
