Environment, pipeline, and how to run it

The raw data stays private, but the structure, the steps, and a reference implementation are all here. A synthetic dataset lets the pipeline run end to end.

🔒
Running against the real 321-response dataset requires access to the private data file. Everything below runs against data/synthetic_sample.csv, which shares the column structure but not the real distributions — so numbers produced from it will not match the paper.

R.3Pipeline, step by step
  1. Load & clean. Read responses, drop duplicate submissions (response-pattern check), apply complete-case filtering per scale.
  2. Build composites. Mean of items per construct. Reverse-score the two efficacy items (6 - x) before averaging them into the burnout composite.
  3. Construct the target. burnout_class = (burnout_score >= median); the median on this sample is 3.29.
  4. Cross-validate. StratifiedKFold(n_splits=5). Inside each fold: fit StandardScaler on train only, transform both; fit each model; score on the held-out fold.
  5. Aggregate. Mean and SD across folds for accuracy, precision, recall, F1, ROC-AUC.
  6. Explain. Refit the Random Forest on the full sample; shap.TreeExplainer → SHAP values for all rows; mean |SHAP| per feature; summary plot.
  7. Regression. Separately, OLS of the continuous burnout score on the four standardised predictors (statsmodels).
R.4Reference implementation

Illustrative — a faithful sketch of the pipeline above, not the verbatim analysis script.

import numpy as np, pandas as pd
from sklearn.model_selection import StratifiedKFold, cross_validate
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.svm import SVC
from sklearn.ensemble import RandomForestClassifier
from xgboost import XGBClassifier
import shap

FEATURES = ["academic_stress", "psych_distress", "self_efficacy", "social_support"]

df = pd.read_csv("data/synthetic_sample.csv")
X = df[FEATURES].to_numpy()
y = (df["burnout_score"] >= df["burnout_score"].median()).astype(int).to_numpy()

models = {
    "logreg": LogisticRegression(max_iter=1000),
    "svm_rbf": SVC(kernel="rbf", probability=True),
    "random_forest": RandomForestClassifier(n_estimators=500, random_state=42),
    "xgboost": XGBClassifier(eval_metric="logloss", random_state=42),
}
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scoring = ["accuracy", "precision", "recall", "f1", "roc_auc"]

for name, clf in models.items():
    pipe = make_pipeline(StandardScaler(), clf)      # scaler fit inside each fold
    res = cross_validate(pipe, X, y, cv=cv, scoring=scoring)
    print(name, {k: round(res["test_" + k].mean(), 3) for k in scoring})

# SHAP on the best model
rf = RandomForestClassifier(n_estimators=500, random_state=42).fit(StandardScaler().fit_transform(X), y)
sv = shap.TreeExplainer(rf).shap_values(StandardScaler().fit_transform(X))
mean_abs = np.abs(sv[1]).mean(axis=0)
print(dict(zip(FEATURES, np.round(mean_abs, 3))))
